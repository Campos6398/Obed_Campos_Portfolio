# Abdominal aneurysm analysis

The project archive is grouped into two working areas:

- `SimVascular/` — patient-specific model, mesh, boundary conditions, MATLAB utilities, flow/pressure/wall-shear animations, and supporting figures.
- `ANSYS/` — Fluent solver comparison and report material.

The `all-files.csv` files preserve the reviewed portfolio names and original paths. Repeated simulation datasets remain excluded from the curated website lists.
