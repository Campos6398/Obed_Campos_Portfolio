# Obed Campos Portfolio

Open index.html locally, or upload index.html, styles.css, script.js, assets/, inventories/, project-file-inventory.csv and image-sources.json and file-name-mapping.csv to GitHub Pages.

The site preserves the original biography, experience, skills, contact details and publications. Project content is organized from the supplied archive. No GitHub repository was modified.

The inventory lists original source paths; it does not bundle 12+ GB of simulation data. Project files shown on cards are file listings, not download links to the originals. The dissertation, defense, resume, CV and extracted website images are bundled.

Run `python3 build.py` to validate local links and produce dist/ for static hosting.

Clear display filenames are used in portfolio lists; original source code files and function names are unchanged. Repeated datasets are omitted from the curated project lists. FILE_NAME_MAPPING.csv maps the reviewed source files to their portfolio names.
